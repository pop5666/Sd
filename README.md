# Pixel Color ไทย (PWA Web Game)

เกมระบายสีตามตัวเลขพิกเซลอาร์ต (Color by Number) พัฒนาด้วย HTML, CSS, JavaScript (Vanilla JS) 100% รองรับการติดตั้งแบบ Progressive Web App (PWA) บนโทรศัพท์มือถือทั้ง Android และ iOS

## ฟีเจอร์เด่น
- 🎨 **50 ด่านพิกเซลอาร์ตสมจริง**: ไม่มีรูปซ้ำกัน 100%
- 📱 **Mobile Optimized**: ซูม ย้ายกระดาน และใช้นิ้วลากลงสีได้อย่างลื่นไหล
- 🖼️ **My Gallery**: คลังบันทึกภาพผลงานที่ระบายสีเสร็จเรียบร้อย
- 🎵 **Sound Effects**: เสียงตอบรับเมื่อระบายสีและโต้ตอบกับปุ่ม UI (ผ่าน Web Audio API)
- 📊 **Stats & Filter**: จัดเรียงตามระดับความยาก-ง่าย พร้อมบันทึกสถิติ
